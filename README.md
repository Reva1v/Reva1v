### About

Full stack developer from Kyiv with 2+ years of commercial experience. I build web apps, internal tools and Telegram bots end to end — React frontends, Node.js and Python backends, PostgreSQL, Docker, CI/CD. Most of my recent work is about putting LLMs and AI agents into real business workflows.

### Recent work

- **Lander Desk** — AI agent platform that takes landing page tasks from ClickUp to verified production deploys. Rust + Tauri, parallel Claude Code agents, Playwright checks. ~91K LOC, 1,800+ tests.
- **UNIC Adapter** — localization platform for 49 markets on a Gemini pipeline. Cut deploy time from ~10 minutes to seconds.
- **Commerce bots** — Telegram and Viber shop that became a client's main sales channel with $25K+ monthly revenue.
